# Changelog

All notable changes to PatchRace will be documented here. Package-specific changelogs are generated by Changesets when the first release is prepared.

## 0.1.0 — 2026-07-24

First stable npm/GitHub release. It adds audited registry publication,
post-publication byte/install verification, an 18-cell macOS/Ubuntu/Windows and
Node 22/24/26 matrix, Windows PID-tree cancellation, portable executable
prefixes, explicit Agent environment pass-through, and a fail-closed live
Pi/Claude Code/Codex parity harness on the PatchRace monorepo. See
[the release notes](docs/releases/v0.1.0.md).

## 0.1.0-rc.2 — 2026-07-23

The second source-only GitHub preview adds a real, budget-bounded Pi + DeepSeek
end-to-end verification and fixes passing trials being assigned a generic
failure diagnosis. A passing trial whose deterministic gates all pass now has
no failure finding and carries an explicit no-failure limitation.

The public repository has also been reduced to user, contributor, architecture,
security, and reproducible verification material. See
[the release notes](docs/releases/v0.1.0-rc.2.md).

## 0.1.0-rc.1 — 2026-07-23

First source-only GitHub preview. It includes the execution core, Pi/Claude
Code/Codex adapters, deterministic grading, comparison reports,
evidence-linked diagnosis, the project-local Pi teaching loop, Pi-native
commands, realistic examples, and release hardening.

This preview was not published to npm. It is superseded by `v0.1.0-rc.2`.
