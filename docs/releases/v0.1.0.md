# PatchRace v0.1.0

Date: 2026-07-24
Channel: stable npm and GitHub release

`v0.1.0` removes the source-preview installation barrier, broadens the
release-gated host/runtime matrix, and makes equal-task live validation across
Pi, Claude Code, and Codex reproducible and explicitly authorized.

## Install

```bash
npx --yes patchrace@0.1.0 --version
# or
npm install --global patchrace@0.1.0
```

For Pi:

```bash
pi install npm:pi-patchrace@0.1.0
```

Ordinary users need Node and Git, but no PatchRace source checkout, Corepack,
pnpm, TypeScript, or local build.

## Release changes

- Publish all nine packages from exact audited tarballs through a protected
  GitHub Actions environment with provenance permission.
- Verify post-publication registry bytes, integrity metadata, clean CLI
  installation, version, and help before creating the GitHub release.
- Support the full 18-cell macOS arm64/x64, Ubuntu 22.04/24.04 arm64/x64, and
  Windows x64 cross product on Node 22.22+, 24, and 26.
- Terminate timed-out Windows Agent descendants by the exact owned PID tree and
  retain the Unix process-group boundary elsewhere.
- Support an explicit executable argument prefix, enabling portable
  script-backed Agent CLIs without shell invocation.
- Validate the npm-installed Windows `patchrace.cmd` package identity and
  invoke the JavaScript entry directly rather than evaluating the shim.
- Hash execution-only argument prefixes in invocation provenance so portable
  script paths do not leak local absolute paths.
- Pin pnpm 11.4 for the supported npm Bulk Advisory API and lock the
  `brace-expansion` high-severity DoS fix.
- Correctly pass explicitly allowlisted environment names into Agent child
  processes without serializing their values.
- Add a provider-free preparer and fail-closed paid runner for the same
  Node-26-support task on the public PatchRace TypeScript monorepo across Pi,
  Claude Code, and Codex.

## Verification

The exact release commit must pass:

```bash
corepack pnpm check
corepack pnpm qa:public
corepack pnpm release:pack
corepack pnpm qa:security
corepack pnpm qa:privacy
```

The protected publication additionally requires all 18 platform cells, the
full release gate, registry byte equality for every package, and a clean
registry installation.

## Boundaries

Git worktrees isolate repository state, not host authority. PatchRace does not
install or authenticate Agent CLIs, infer unavailable usage/cost as zero,
upload raw evidence, or claim that one live task establishes universal model
quality. Codex cost is unavailable in the supported stream, so its monetary
ceiling remains an explicit provider authorization rather than a falsely
claimed PatchRace-enforced signal.
