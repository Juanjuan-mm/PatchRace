# PatchRace v0.1.0-rc.1

Release type: source-only GitHub preview  
Date: 2026-07-23

PatchRace races Pi, Claude Code, and Codex on reproducible repository tasks,
grades correctness first, diagnoses observable workflow differences, and
stages reviewable project-local Pi improvements for held-out validation.

## Install

This preview is not published to npm. Clone the tagged source, then run:

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm docs:quickstart
```

The quickstart uses deterministic local fixtures and requires no Agent
credential or paid API call. Read
[the full installation guide](../INSTALLATION.md) before running on a real
repository.

## Included

- durable, budgeted Git-worktree execution and recovery;
- Pi, Claude Code, and Codex structured adapters with readiness/version checks;
- deterministic setup, test, hidden-verifier, and assertion gates;
- correctness-first repeated-run comparison and JSON/HTML/JUnit/SARIF output;
- evidence-linked diagnosis with conservative insufficient-evidence and
  capability-gap outcomes;
- project-local Pi guidance/Skill/prompt candidate staging, review, validation,
  selection, promotion, and rollback;
- Pi-native race, coach, candidate, status, promotion, and rollback flows;
- source quickstart plus TypeScript, Python, and POSIX-shell examples.

## Verification

- 55 deterministic dogfood runs across 10 tasks and all three adapters;
- 50 expected passes and 5 classified Agent failures;
- 10 interruption/cleanup scenarios with zero orphaned owned worktrees;
- macOS and Ubuntu arm64/x64 clean-source evidence on Node 22 and 24;
- full TypeScript quality, fixture, build, smoke, package-content, license,
  security, privacy, documentation, and release-candidate checks;
- nine version-aligned `0.1.0-rc.1` package tarballs dry-packed locally;
- no known unresolved critical/high security or privacy defect.

## Important limitations

- Independent-user beta is 0/5. `ADR-022` waives that gate only for this
  preview; it is not reported as passed.
- This is not a stable release and no npm package has been published.
- Maintained deterministic fixtures do not establish live-model quality,
  universal Agent rankings, or general workflow-transfer claims.
- Worktrees are not a host sandbox. Repository and Agent processes retain the
  invoking user's filesystem, credential, process, and network authority.
- Raw runs and reports can contain private code, prompts, paths, or unknown
  secret formats. Keep them local; review the bounded shareable projection
  before any explicit export.
- Windows, macOS Intel, WSL, non-Ubuntu Linux, Node outside the documented
  range, and unlisted Agent CLI versions are not release-gated.

## Feedback

When reporting a defect, include the PatchRace version, supported environment,
exact command, expected/actual behavior, and the smallest public-safe
reproduction. Do not attach raw traces, private repositories, credentials,
personal paths, or unreviewed local reports.

Use the repository's private vulnerability-reporting flow for suspected
security issues or accidental sensitive-data exposure.
