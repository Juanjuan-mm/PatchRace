# PatchRace v0.1.0-rc.2

Released: 2026-07-23  
Channel: source-only GitHub prerelease

`v0.1.0-rc.2` is a local-first preview for racing Pi, Claude Code, and Codex on
reproducible repository tasks, grading deterministic correctness, inspecting
observable evidence, and staging reviewable project-local Pi improvements.

## Highlights

- deterministic task, trial, budget, grading, report, diagnosis, and cleanup
  workflows;
- Pi, Claude Code, and Codex structured CLI adapters;
- standalone HTML, JSON, JUnit, and SARIF output;
- explicit train/validation/holdout separation for Pi candidates;
- provider-free five-minute quickstart;
- a real budget-bounded Pi + DeepSeek end-to-end check;
- a regression fix so passing trials no longer receive generic failure
  diagnoses.

## Install

This prerelease is not published to npm. Use the tagged source:

```bash
git clone --branch v0.1.0-rc.2 --depth 1 \
  https://github.com/songjinmiao/PatchRace.git
cd PatchRace
corepack pnpm install --frozen-lockfile
corepack pnpm docs:quickstart
```

Do not install an unrelated registry package named `patchrace`. See
[installation](../INSTALLATION.md) for supported Node, Git, operating-system,
and real-repository instructions.

## Verification and limits

The source passes 75 test files and 246 tests, platform/package/security/privacy
checks, realistic examples, and one small live-provider task. Exact evidence
and claim boundaries are in [VERIFICATION.md](../VERIFICATION.md) and
[LIVE_E2E.md](../LIVE_E2E.md).

PatchRace is not a host sandbox. Worktrees isolate Git state only. Agent CLIs
and trusted repository commands can access the invoking user's filesystem,
processes, credentials, and network. Raw traces and reports may contain private
data; publication is always opt-in and must be reviewed.
